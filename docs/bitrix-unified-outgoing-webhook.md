# Единый исходящий webhook Bitrix24 -> Supabase

## Что оставляем

Используйте один исходящий webhook Bitrix24 c URL:

`https://<project-ref>.supabase.co/functions/v1/reference-sync?token=YOUR_SECRET_TOKEN`

Эта функция теперь обрабатывает:

- HR smart process `1050`: пересчёт дней и заполнение должности в родительном падеже;
- компании: обновление snapshot справочника компаний;
- smart process договоров `1060`: обновление snapshot компаний/договоров;
- при необходимости: события метаданных полей для обновления справочников.

## Какой старый webhook отключить

После переключения URL можно отключить исходящий webhook, который сейчас указывает на:

`/functions/v1/bitrix-hr-days-spell`

Саму Supabase Edge Function `bitrix-hr-days-spell` можно оставить в коде как резервную, но в Bitrix она больше не нужна.

## Рекомендуемый минимальный набор событий

Оставить обязательно:

- `ONCRMCOMPANYADD`
- `ONCRMCOMPANYUPDATE`
- `ONCRMCOMPANYDELETE`
- `ONCRMDYNAMICITEMADD`
- `ONCRMDYNAMICITEMUPDATE`
- `ONCRMDYNAMICITEMDELETE`

Этот набор покрывает:

- HR `1050` через фильтрацию по `ENTITY_TYPE_ID` внутри `reference-sync`;
- договоры `1060` через ту же фильтрацию;
- компании напрямую.

## Опциональные события

Оставляйте только если нужен авто-sync справочников после изменения настроек полей:

- события с `USERFIELD`
- события с `SETENUMVALUES`

Если важнее производительность и стабильность Bitrix, эти события лучше убрать и запускать `reference-sync` вручную из интерфейса приложения, когда администратор меняет справочники или настройки полей.

## Порядок переключения

1. Задеплойте актуальный `reference-sync`.
2. В одном исходящем webhook замените URL на `reference-sync`.
3. Перенесите в него обязательные события из двух старых webhook.
4. Сохраните и протестируйте:
   - изменение HR-элемента `1050`;
   - изменение компании;
   - изменение договора `1060`.
5. После проверки отключите старый webhook на `bitrix-hr-days-spell`.

## Что получится в итоге

- 1 исходящий webhook Bitrix24
- 2 входящих webhook Bitrix24
- меньше лишних вызовов Supabase
- нет тяжёлого full sync на каждом HR-событии
